# Fotografias pessoais

- foto-principal.webp → usada no Hero (início)
- foto-sobre.webp → usada na seção "Sobre"

Os caminhos ficam em `src/data/profile.ts` → `photos`. Para trocar uma foto,
substitua o arquivo mantendo o mesmo nome ou altere o caminho no arquivo de
dados. Se o caminho for `null`, o site mostra um fallback com o monograma.

Estas são versões otimizadas (WebP). Os arquivos originais, em alta resolução,
ficam na pasta `originais/` na raiz do projeto, que não é publicada.
